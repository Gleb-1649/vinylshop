# Магазин винила





Сайт https://gleb-1649.github.io/vinylshop/





Магазин виниловых пластинок. Работа выполнена в рамках первой лабораторной

по веб-программированию. Использованы HTML, CSS и JavaScript.



Работа магазина



В каталоге можно выбрать пластинки и добавить их в заказ.

В таблице корзины доступны изменение количества и удаление.

После ввода количества нужно нажать Enter или выйти из поля.

Общая сумма пересчитывается, изменения сохраняются в localStorage.



Для оформления нужно заполнить имя, фамилию, адрес и контактный телефон.

После этого появляется Заказ создан!. Корзина очищается, можно собрать новый заказ.



Есть адаптация под телефон и планшет. Таблица на маленьком экране

прокручивается внутри своего блока.



Как открыть



Открыть проект в VS Code и запустить `index.html` с помощью Live Server.

Устанавливать зависимости проекта не нужно.



Разметка лежит в `index.html`, оформление в `styles.css`,

вся логика в `script.js`.
