# Магазин винила



В каталоге четыре вымышленных альбома. Выбранные пластинки попадают в таблицу,

где можно изменить количество и удалить товар. Корзина сохраняется в localStorage.



Добавлено оформление: по кнопке открываются поля имени, фамилии, адреса

и телефона. Все поля обязательны. Если всё заполнено, выводится Заказ создан!

и корзина становится пустой. 



Запуск через Live Server в VS Code: открыть папку и запустить `index.html`.

Стили находятся в `styles.css`, обработчики и сохранение в `script.js`.
