# Сторона Б

Магазин виниловых пластинок для первой лабораторной. HTML и CSS отвечают за страницу, JavaScript за корзину.

Товар добавляется кнопкой под описанием. В корзине можно ввести количество пластинок или удалить строку. 

Стоимость обновляется после изменения количества. Ноль, отрицательные и дробные числа не принимаются.

Основные файлы: index.html, styles.css, script.js. Запускается открытием index.html в браузере.

Сохранения пока нет: после перезагрузки корзина пустая. Форма заказа ещё не работает.
