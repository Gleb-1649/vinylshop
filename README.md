# Магазин винила

[Открыть сайт](https://gleb-1649.github.io/vinylshop/)

Учебный магазин пластинок на HTML, CSS и JavaScript.
Каталог показан списком. Его можно отсортировать по цене, году или исполнителю.
Релизы добавляются в таблицу заказа. Количество меняется числом от 1 до 20,
Enter или выход из поля пересчитывает сумму. Есть удаление и сохранение корзины. Изменение числа обновляет сумму в строке,
не пересоздавая всю таблицу. Ошибки сохранения видны на странице.

Данные каталога теперь находятся в catalog.js. script.js заполняет ими шаблон
карточки из index.html и берёт оттуда же цены для корзины. styles.css отвечает
за оформление. Если сохранённый заказ не загрузился, появляется сообщение.

Для оформления нужно указать имя, фамилию, адрес и телефон.
После отправки формы появляется «Заказ создан!». Это учебная демонстрация.

Запуск: открыть index.html в браузере или через Live Server, без установки пакетов.

## Обложки

У каждого релиза есть своя обложка. Четыре изображения лежат в папке images в формате JPG.
В catalog.js поле image содержит путь к картинке. В шаблоне карточки стоит обычный
тег img, а script.js задаёт ему src и alt.
