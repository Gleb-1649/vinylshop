# Сторона Б



К HTML добавлен файл `styles.css`. У страницы светлый фон и синяя шапка,
пластинки расположены в две колонки. На узком экране остаётся одна колонка,
таблицу корзины можно прокручивать по горизонтали внутри её блока.

Открыть `index.html` в браузере для просмотра.
Добавление товаров и оформление заказа будут подключены дальше.
